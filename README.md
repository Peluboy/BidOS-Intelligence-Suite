# BidOS Intelligence Suite 🚀
### The Ultimate AI-Driven Scouting & Strategy Layer for Upwork Professionals.

BidOS is a high-performance Chrome Extension designed to transform the Upwork experience from a "guessing game" into a data-driven system. It combines real-time background scouting, deep client analysis, and persona-driven AI proposal generation.

## 🌟 Key Features
- **Background Scout**: Real-time notifications for jobs matching your specific persona.
- **Client Intelligence**: Deep-dive analytics on client hire rates, spend, and quality.
- **ROI Engine**: Visual indicators of whether a job is worth your Connects.
- **Scope Estimator**: Instant project pricing and Not-to-Exceed (NTE) budget generators.
- **Strategic AI Pitching**: Generate high-conversion proposals using expert-tuned strategies.

## 📥 Installation (v1.2.0)
To ensure the security and integrity of the BidOS core engine, the source code is obfuscated and distributed via secure builds.

1. **Download the latest release**: Go to the [Releases](https://github.com/Peluboy/BidOS-Intelligence-Suite/releases) section and download `BidOS_v1.2.0.zip`.
2. **Unzip the file** to a permanent location on your computer.
3. **Open Chrome** and navigate to `chrome://extensions/`.
4. **Enable "Developer Mode"** (top right toggle).
5. Click **"Load unpacked"** and select the folder you just unzipped.
